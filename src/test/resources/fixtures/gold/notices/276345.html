3. 신청방법(반드시 둘 다 신청해야함)

         : 학사정보 → 등록/장학 → 장학금신청 → ‘추가’ 클릭 후 장학 종류 선택 → 저장

  나) 자기소개서 제출(붙임2)

         : 각 직무인턴 담당자에게 자기소개서 필수 제출

4. 유의사항

  가) 직전학기 15학점/2.5이상인 자(※ 신·편입학 첫학기는 성적기준 적용 안함)

  나) 근로 및 인턴십 장학금은 등록금 범위 초과 수혜 가능

  다) 2026-2학기 기준, 정규학기(8차 학기 내) 재학인 학생 신청 가능

  라) 직무인턴/국가근로 중 한가지만 활동할 수 있음

  마) 2026-2학기 국가근로 신청 후 미선발된 학생은 신청 가능함
